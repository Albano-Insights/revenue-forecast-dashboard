# Revenue Forecast Dashboard

A consumption-based revenue forecast: interactive dashboard, slide deck and decision log.

| | |
|---|---|
| **[Dashboard](https://albano-insights.github.io/revenue-forecast-dashboard/)** | Six views with global segment x region filtering |
| **[Slides](https://albano-insights.github.io/revenue-forecast-dashboard/slides.html)** | 17 slides; press `o` for the overview |
| **[Decision log](https://albano-insights.github.io/revenue-forecast-dashboard/decision-log.html)** | Every modelling judgement and its evidence |

Built on a synthetic dataset. The dashboard is a single self-contained file; it loads Chart.js
from cdnjs and fonts from Google, and needs no server.
